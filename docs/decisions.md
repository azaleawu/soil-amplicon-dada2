# 给土壤扩增子项目选路线

一次研究、一次测序批次、一个公开 SRR 和一个物理土样可能对应四种不同的单位。先从 Methods、归档元数据和测序交付表中填写它们的关系，然后决定哪些文库适合放在同一张 ASV 表里。

| 拿到的数据 | 分析选择 | 得到的比较单位 |
|---|---|---|
| 细菌或古菌 16S，已知 V4、V3–V4 等区段 | 根据每批次 R1/R2 质量和预期片段长度选截断位置，保留足够的拼接重叠。使用 SILVA 的 DADA2 训练集 | 同引物、同方向、覆盖相同区段的 ASV。单独记录古菌特异引物 |
| 真菌 ITS1、ITS2 | 分别建组。考虑短插入片段读穿对侧引物；成对全片段分析的起点是两端均不定长截断。检查拼接保留率是否随片段长度变化 | 同一 ITS 子区、相同读法。记录 UNITE 版本及 fungi-only / all-eukaryotes 选择 |
| 土壤真核生物 18S | V4/V9 分组。元生生物分析从真核 18S 分类表中按定义选取类群；公开 PR2 的 DADA2 训练集有明确的分类阶元 | 标记和引物一致的 ASV；下游保留目标类群筛选记录 |
| 只有 R1，或 R1/R2 无法有效重叠 | 如需单端，建立独立的 R1 组，按相同方向和末端重新处理该比较组的所有文库，记录成对数据退回 R1 的依据 | 同方向、同有效终点的单端 ASV。成对合并的整段 ASV 单独保留 |
| FASTA、SRA Lite、全 Q30/Q3、或来源不明的质量值 | 优先找 ENA 原始提交文件或 SRA Normalized 完整质量数据。质量简化且无法恢复时，单列技术分析，单独说明误差模型、质控和可比性 | 该版本执行标准质量感知 Illumina 流程。历史的 no-quality 技术试验可以单独存档 |
| 长读长、混合方向、Ion Torrent | PacBio CCS/HiFi 见作者长读长流程，Ion Torrent 见 DADA2 FAQ 或相应工作流。混合方向文库先单独定向并核查引物位置 | 单独的平台或建库路线。记录读长、方向、平台专用参数 |
| 功能基因或菌根真菌 LSU | 在来源目录中选相应参考工作流，核对目标区、专用数据库和分类/翻译验证 | 由功能基因或 LSU 的研究问题定义 |

**跨研究合表。** 同一分析组内核对 marker、locus、实际引物序列、方向、布局和保留区间。代码按序列的 SHA-256 生成稳定 ASV ID；分别为各测序批次学习误差，随后在同一分析组汇集精确序列计数。同一序列 ID 在不同组出现仅说明序列字符串相同。若引物覆盖不同，可在各研究内估计生态效应，再按可比设计汇总。若选择分类层级汇总，先统一数据库和阶元，并评估引物偏倚。

**选截断位置。** 对去引物后的插入片段，预期重叠约等于保留的 R1 长度 + 保留的 R2 长度 − 插入片段长度。固定长度的扩增区可用其长度范围进行估算，变长 ITS 需要检查长度分布的长端。确认各 run 的过滤、合并、去嵌合体保留率，再确定正式参数。R1-only 定长时，同组所有 run 使用同一截断位置，并确认起点相同。单端变长读段只有在能确认共同的生物学末端时才可按整段做跨 run 的精确比较。

**ITS 区域不确定。** 若公开记录只写“ITS”，回查引物、论文补充材料和扩增子注释。必要时用 ITSx 定位可识别的区段，并统计按 reads 加权的覆盖度。一个暂未定性的 assay 可在独立组内做技术分析，保留明确的临时 locus 名称。比较 ITS1 与 ITS2 研究前，需要有支持相应比较尺度的证据。

**主分析与敏感性。** 选定一个主参数表。比如测试 R2 的最大预期错误数时，复制参数表只改 `max_ee_r`，对同一组已经去引物的 reads 运行至新的输出目录。追踪多留下的 reads 在过滤、拼接和去嵌合体的哪一步产生；用序列 ID 检查共有或独有 ASV 的丰度。主分支和敏感性分支的 reads 有重叠，分别报告。

**剖面、样品与对照。** 用 study_id + profile_id 标识土壤剖面，sample_id 标识物理样品，library_id 标识文库。保留 top/bottom depth (cm)、原始 horizon、混样信息、坐标来源和精度。相同样品的技术重复可在确认对应关系后汇总。混样和同一剖面的不同土层不能充当独立剖面重复。阴性对照、阳性对照和 mock 可进入同批去噪并保留 sample_type。在下游记录空白中的信号、非目标类群、叶绿体或线粒体 ASV 和每一步去除的 reads；本流程输出未做生态筛选的原始非嵌合体计数。
